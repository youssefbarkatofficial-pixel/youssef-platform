# الحزمة 4د: السرعة والـ SEO وتنظيف الكاش القديم

## ما الجديد
1. **تحميل الصفحات بالتدريج**: الملف الرئيسي نزل من 848 كيلوبايت إلى 50 كيلوبايت (مع ملفين منفصلين للمكتبات يُحفظان في كاش المتصفح).
2. **كل الصفوف**: الرابع والخامس والسادس الابتدائي، والإعدادي بالثلاثة، والثانوي بالثلاثة، في الكود وفي قواعد الأمان (`firestore.rules.new`)، ودالة `normalizeGrade` تفهم الأسماء العربية القديمة لها.
3. **SEO**: عنوان الموقع ووصفه وعلامات المشاركة وبيانات جوجل المنظمة (JSON-LD) منقولة من الموقع القديم حرفيًا، وملفا إثبات جوجل، و`robots.txt` و`sitemap.xml` (فيه الكورسات الثلاثة الحقيقية).
4. **تحويلات الروابط القديمة** (`public/_redirects`): `courses.html` و`login.html` و`register.html` و`dashboard.html` وغيرها تتحول بـ 301 للرابط الجديد. أما `course-details.html?id=...` فيتحول بمكوّن React (`LegacyCourseRedirect`) إلى `/courses/رقم_الكورس`.
5. **`public/sw.js` ذاتي الحذف**: المنصة القديمة سجّلت `./sw.js` في متصفحات الطلاب. هذا الملف يمسح الكاش القديم ثم يلغي نفسه حتى لا يرى أي طالب نسخة قديمة.
6. **`manifest.json`** بنفس ألوان وأيقونات القديم (لمن ثبّت المنصة على الموبايل).

## ما لم يتغير
لا تغيير في أي قاعدة بيانات أو Firebase، ولا نشر. قواعد الأمان ملف فقط.
الـ sw.js والتحويلات لا تعمل محليًا (على `localhost`)، فقط بعد النشر على Cloudflare Pages يوم الاستبدال.

## التجربة
1. `npm install` ثم `npm run build` (المفروض بدون أخطاء).
2. `npm run dev` وافتح `/` و`/courses` و`/login`، وجرّب `http://localhost:5173/course-details.html?id=c1785199571849` فيتحول إلى `/courses/c1785199571849`.
3. في صفحة التسجيل، قائمة الصفوف فيها 9 صفوف الآن.
