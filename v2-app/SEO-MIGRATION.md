## د) اسم متغير الرابط (query param) في course-details.html

```
?id=COURSE_ID
```

**مثال:** `course-details.html?id=abc123`

الكود المستخدم في الصفحة القديمة:
```javascript
const params = new URLSearchParams(window.location.search);
const courseId = params.get('id');
```

في المشروع الجديد، القيمة تُمرَّر كـ URL param لا query param:
- القديم: `/course-details.html?id=abc123`
- الجديد: `/courses/abc123`

عند تنفيذ الاستبدال، يجب ان يحوّل ملف `_redirects` الرابط القديم الى الجديد:
```
/course-details.html /courses/:id 301
```
*(هذا للمرجع فقط - لا تنفّذه الان)*
