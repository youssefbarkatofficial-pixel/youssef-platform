# المرحلة 5: اللوحات والإحصائيات والدعم والإشعارات وأدوار الأدمن

> **مهم:** هذه الحزمة لم تُبنَ ولم تُجرَّب بعد (البناء لم يتوفر وقت كتابتها). أول خطوة: `npm install` ثم `npm run build` وأرسل النتيجة كما هي.

## ما الجديد

**للطالب**
- **لوحتي**: رسالة الترحيب، معدل الالتزام، عدد الكورسات والامتحانات، الإشعارات (تعليم الكل كمقروء وحذف)، آخر الدرجات.
- **الإحصائيات**: معدل الالتزام، المستوى العام، نسبة المشاهدة، متوسط الامتحانات والواجبات والتدريبات، وأداؤه في كل كورس.
- **الدعم الفني**: يرسل سؤالًا أو شكوى ويتابع الردود ويرد.
- في صفحة الكورس: زر **"أنهيت المشاهدة"** تحت الفيديو (يغذي الإحصائيات).

**للأدمن**
- **الرئيسية**: عدد الطلاب والكورسات والطلبات المعلقة، إجمالي الدخل، مستويات الطلاب (متفوق/متوسط/ضعيف)، أعلى الكورسات دخلًا، آخر الطلبات.
- **الطلاب**: بحث وفلتر بالصف، آخر ظهور، تجميد الحساب بدل الحذف، وصفحة تفاصيل لكل طالب (المستوى العام ومكوناته وسجل المحاولات).
- **الإشعارات**: إرسال لكل الطلاب أو صف أو مشتركي كورس، مع سجل بآخر ما أُرسل.
- **الدعم الفني** (للأدمن الكامل فقط): الرد وإغلاق التذاكر.
- **الإعدادات**: قفل التسجيل، رسالة الترحيب، وإدارة المشرفين (للمالك فقط).
- **المدفوعات**: زر **تصفير الدخل** (للمالك والأدمن الكامل) بدون حذف أي طلب.

**أدوار الأدمن**
- المالك: كل شيء. أدمن كامل: كل شيء عدا إدارة المشرفين. مساعد: الطلاب والمدفوعات والإشعارات والكورسات، ولا يرى الدعم الفني ولا البوصلة ولا يصفّر الدخل.

## قواعد الأمان (`firestore.rules.new`، ملف فقط وغير منشور)
أُضيف: `support_tickets`، `sent_notifications`، دور المساعد، تعطيل المشرف بحقل `active`، تصفير الدخل بحقل `archived_revenue` وحده، وقفل التسجيل يُطبَّق في القواعد أيضًا. وأُضيفت لها اختبارات في `tests/rules`.

## جرّب
1. `npm install` ثم `npm run build` (أرسل أي خطأ كما هو).
2. `npm run dev`: لوحة الطالب والإحصائيات والدعم، ولوحة الأدمن الجديدة.
3. بعد تثبيت JDK 17: `npm run test:rules` وأرسل المخرجات (لازم تنجح كلها قبل أي نشر).
